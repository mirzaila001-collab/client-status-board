۰۴ · کار باز

  1. علت افت لایو بررسی شود. سایت جدید وارد این بررسی نمی‌شود.
  2. دو سری چهارتایی: ثبت برند، و ثبت شرکت.
  3. همان محتواها دوتا دوتا منتشر شوند.
  4. سایت جدید: دیزاین تا مرحلهٔ انتشار، بعد انتقال محتوا.

۰۵ · آینده، کوتاه

  2. هشت محتوا: چهار تا برای ثبت برند، چهار تا برای ثبت شرکت.
  3. انتشار همان هشت تا، هر نوبت دو عدد، روی لایو.
  4. بعد از مسیر لایو، دیزاین سایت جدید تا جایی که بشود منتشرش کرد و محتوا را برد.
